# Preguntas para revisión metodológica del IEE v1

**Estado:** guía de consulta; no es una aprobación  
**Fecha:** 2026-09-03

1. ¿La definición propuesta de eficiencia evita confundir bajo gasto con mejor desempeño?
2. ¿Los periodos y rezagos por dimensión son comparables o deben permanecer separados?
3. ¿La regla de 30 países es suficiente para un corte experimental y cómo debe justificarse?
4. ¿Qué función deben tener acceso, equidad y contexto: condición, ajuste o reporte paralelo?
5. ¿Qué normalización y análisis de sensibilidad permiten evitar que valores extremos dominen?
6. ¿Qué evidencia es necesaria para aceptar un insumo hoy marcado como condicional?
7. ¿Qué debe publicarse para que terceros reproduzcan o cuestionen el corte?

Las respuestas deben distinguir recomendaciones metodológicas de decisiones del
proyecto, indicar conflictos de interés cuando existan y citar su fundamento.
