# ADR 0033: protocolo de lanzamiento del IEE v1

- **Estado:** adoptado como regla de publicación
- **Fecha:** 2026-09-03

## Contexto

El proyecto cuenta con código, fuentes y sensibilidades reproducibles, pero no
con una cohorte completa ni un contrato metodológico v1 congelado. Publicar
resultados parciales como ranking podría presentar una certeza inexistente.

## Decisión

Se adopta un lanzamiento escalonado: tablero de trazabilidad, corte experimental
y, únicamente después de cumplir puertas verificables, IEE v1 oficial. Cada
puerta fallida bloquea el ranking, incluso cuando el resto del sistema funcione.

## Consecuencias

El proyecto puede mostrar progreso y evidencia ahora, sin esperar financiación o
servicios pagos. A cambio, se pospone cualquier ranking hasta contar con una
cohorte comparable, método congelado, sensibilidades separadas y revisión abierta.
