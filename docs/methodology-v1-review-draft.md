# Borrador metodológico IEE v1 para revisión

**Estado:** borrador de revisión; no congelado  
**Fecha:** 2026-09-03

## Propósito propuesto

El IEE debe comparar la capacidad de transformar recursos públicos en resultados
sociales e institucionales, sin premiar automáticamente el tamaño del Estado.
La unidad propuesta de comparación es cada país del universo previamente fijado,
con resultados, recursos, acceso/equidad y contexto tratados como roles distintos.

## Límites que no cambian en este borrador

- Ningún insumo condicional se transforma en puntaje por esta publicación.
- Contexto, acceso y equidad no se suman automáticamente a resultados.
- Una sensibilidad no reemplaza el contrato base.
- Faltantes se declaran y excluyen; no se imputan para alcanzar una muestra.
- No se publican puestos, calificaciones generales ni rankings.

## Decisiones que requieren revisión antes de congelar v1

1. Definir la ventana temporal común para cada resultado y su recurso asociado.
2. Declarar la cohorte común y la regla de exclusión antes de mirar resultados.
3. Elegir una normalización robusta y su tratamiento de valores extremos.
4. Definir si acceso/equidad funciona como requisito, ajuste o reporte paralelo.
5. Justificar pesos entre dimensiones o usar una alternativa sin pesos fijos.
6. Establecer umbrales y respuestas ante sensibilidad metodológica.

La aceptación de una de estas decisiones debe quedar versionada, con argumentos y
comentarios recibidos. Hasta entonces, este documento no habilita agregación.
