# Protocolo candidato: acceso administrativo por pasaporte v2.1

Este protocolo prepara una comparación futura de la experiencia de obtener o
renovar un pasaporte regular. No contiene observaciones, no crea un indicador y
no afecta puntajes.

## Caso de referencia

| Campo | Definición requerida |
|---|---|
| Persona | Adulta, ciudadana, solicitud doméstica |
| Servicio | Pasaporte regular, primera expedición o renovación documentada por separado |
| Modalidad | No expedita; sin urgencia, consulado ni intermediario privado |
| Inicio | Primer momento en que puede presentarse una solicitud completa |
| Final | Documento disponible para recoger o entregado al solicitante |
| Período | Año calendario o trimestre identificado |

## Datos mínimos por país

- Fuente operativa oficial y enlace permanente.
- Universo de solicitudes y número de casos.
- Mediana o percentiles del tiempo total; una media solo si no existe una medida
  de distribución.
- Tiempo de cita, verificación, producción y entrega, o una declaración expresa
  de que el componente no está medido.
- Costo obligatorio y canal de presentación.
- Fecha de extracción, responsable institucional y notas de cambios operativos.

## Regla de admisión

Una observación es comparable únicamente si los dos países comparten el mismo
inicio, final, población y modalidad. Si un país reporta tiempo posterior al
pago y el otro desde recepción de la solicitud, ambos se clasifican como
incomparables hasta encontrar una fuente que permita reconstruir los componentes.

## Estado actual

Colombia publica entrega posterior al pago; Estados Unidos publica procesamiento
en agencias o centros y excluye el correo. Esas definiciones son insuficientes
para materializar una brecha, un promedio o un ranking. La
[ADR 0025](decisions/0025-v21-passport-access-protocol.md) registra esta decisión.
