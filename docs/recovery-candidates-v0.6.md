# Rutas candidatas de recuperación v0.6

Tres fuentes públicas pasan al siguiente paso técnico: Australia/ABS para educación,
Grecia/Eurostat COFOG para educación y Alemania/Eurostat para mortalidad evitable.
No se adoptan observaciones todavía: cada ruta debe demostrar igualdad de
definición, ventana y transformación antes de modificar una sensibilidad.

Bélgica, Canadá e Islandia continúan bloqueados. El registro v0.6 mantiene las
rutas candidatas separadas de cualquier integración, puntaje o cambio de cohorte.
